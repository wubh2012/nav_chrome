# 方案 1：像素木牌 HTML 原型

运行：在项目根目录执行 `node docs/prototypes/orchard-directions/pixel-labels/preview.cjs`，打开 http://127.0.0.1:8787/。

入口是 `index.html`，也可以直接打开该 HTML 文件；它通过相对路径复用项目现有模块、字体和果园资源。网页是可交互的 HTML，不是方案图贴图。

设计参考为上一级目录的 `01-pixel-labels.png`。保留正式首页上半部分的结构与果园交互，网站列表改为四列横向浅色木牌，分类按钮使用像素边角。小于 900px 时三列，小于 680px 时两列；长名称保留完整 title 和无障碍名称，窄屏显示省略号。

## 数据

本机原型使用 2026-10-04 从当前开发版 Chrome 扩展导航缓存读取的快照：76 个网站，主页 38、AI 26、Code 5、其他 2、影视 5。快照只保留名称、网址、图标、ID、分类和排序，不包含飞书凭据。

`actual-data.js` 和 `actual-data.json` 是本机实际数据，已通过本目录 `.gitignore` 排除。含实际收藏的 QA 截图也排除。若在其他机器使用，需要自行提供导航快照；未提供时会回退到项目自带的演示网站。

在开发版扩展上下文打开本目录页面时，bootstrap 也支持读取当前导航缓存。该入口尚未通过 Chrome 连接验证；已验证的预览是 HTTP 快照入口。

所有新增、删除、整理、果园和显示设置操作都写入页面内存，刷新后恢复原快照，不调用飞书同步、不修改实际扩展存储。

## 验证

已在浏览器检查真实分类筛选、快速搜索、内存新增、刷新恢复、整理模式、果园收获、字体设置对话框和深浅模式。检查了 390px iframe 的窄屏显示，没有横向溢出。JS 语法检查通过，原型浏览器控制台没有错误。

视觉对照与已接受差异见 `design-qa.md`。预览依赖项目现有资源；正式扩展打包清单不包含 docs 中的原型。
