# 首页设计：D 像素果园

状态：用户已确定 D 方案，已接入正式首页。

最初探索了 A 数字果园、B 极简书签架、C 水果便签板、D 像素果园。用户选择 D，并希望增加摘果、种树、逗猫等轻互动；后续确认了装扮果园与池塘小鱼。

## 这次细化

首页移除横排玩法按钮，仅保留一句轻提示和「我的果园」入口。果树、树苗、小猫、池塘可直接点击，悬停和键盘聚焦时显示反馈。展开果园面板后，按需种树、浇水、装扮；「去果园散个步」提供手机和键盘更容易操作的入口。点击外部或 Escape 收起面板。

天空蓝 `#def0fa`、草地 `#ccdfa5`、叶绿 `#448664` 与杏色果实 `#f2af83` 构成主要视觉。系统中文字体搭配 Consolas 时钟，像素场景与网站启动区相接。默认不自动播放动画，不产生声音，尊重减少动态效果设置。

## 正式功能

- 接入现有分类、快速搜索、添加 / 编辑 / 删除、拖拽排序、时间聚焦、设置及飞书同步模块。
- 网站编辑 / 删除入口在桌面悬停时出现；手机通过标题旁的「整理网站」开关展开。
- 1.0.7 已加入五条成长路线、探索与自由布置，当前规则见 [木牌果园玩法](orchard-gameplay.md)。新进度保存在 Chrome 本地键 `chromeNav_orchard_v2`，首次使用迁移 `chromeNav_pixelGarden_v1` 并保留旧存档，不写入飞书。
- 存档只接收已知字段；损坏字段按合理默认值恢复，未来版本存档报错并保留，避免静默覆盖。
- 早期首页原型保留作历史设计记录；本次确认的玩法原型归档在 `codex/orchard-gameplay-prototype` 分支。正式 `PixelGarden` 已独立重写，`/newtab.html` 不包含原型切换条。
