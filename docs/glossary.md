# 术语表

## 皮肤（Skin）

界面的视觉调色板。目前包括石墨中性、霓虹风格和奶油复古。皮肤决定颜色、表面、边框和强调色，但不决定使用哪张自定义背景图片。

## 明暗模式（Theme mode）

界面的浅色或深色状态，取值为 `light`、`dark`。每个明暗模式拥有一套独立背景档案。页面上的太阳/月亮按钮用于切换明暗模式。

## 背景模式（Background mode）

单个背景档案的图片来源，取值如下：

- `default`：使用当前皮肤和明暗模式生成的默认 Art Deco 背景。
- `upload`：使用保存在浏览器 IndexedDB 中的本地上传图。
- `url`：使用用户提供的 HTTP 或 HTTPS 图片地址。

## 背景档案（Background profile）

某一明暗模式的完整背景设置，包括背景模式、图片 URL、适配方式、位置、遮罩强度、模糊强度和更新时间。浅色与深色档案互不覆盖，三套皮肤共同使用它们。
