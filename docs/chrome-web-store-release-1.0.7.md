# 水果导航 1.0.7 发布说明

- 版本号：`1.0.7`
- 本地安装包：`dist/shuiguo-nav-chrome-1.0.7.zip`
- 日期：2026-10-14

木牌果园增加按需展开的探索窗口，包含自由布置、隐藏谜题、动物来访，以及种植、采集、钓鱼、制作和关系五条成长路线。首页继续以时钟、搜索和网站木牌为主；正式版不提供原型场景切换、快进或重置按钮。

果树和苗床按真实时间生长；关闭页面后继续成长，成熟的收获保留到玩家回来。果园昼夜使用设备本地时间，果园小雨是本地生成的场景天气，不获取真实天气或位置。日常拾取、鱼种首次收获、交谈和赠礼按本地日期记录。

自由布置支持多件物品、拖动、键盘移动、转向、四种配色、收回与撤销；河流、苗床、谜题和物件占位受到保护。布局与物件组合可以吸引不同动物，发现进入自然手记。料理和物件可用于布置或赠送朋友，关系推进原创故事与小信。Lv.2 提供具体解锁，之后保留熟练度成长。

新存档独立保存在 `chromeNav_orchard_v2`。首次使用迁移旧版 `chromeNav_pixelGarden_v1` 的果篮、树苗、四棵基础果树、装饰、鱼类与互动开关，旧存档保留作为备份。后台依次处理操作，多个标签页读取最新状态后提交，通过存储事件同步界面。果园不写入飞书，不改变导航数据与经典分类布局。

本地验证包括核心规则与资源边界、旧存档迁移、离线成熟、并发操作、写入失败、真实扩展 Service Worker、Chrome 本地存储、刷新恢复、跨标签页同步、390px 窄屏、自由布置、主动钓鱼、原有搜索快捷键和经典布局。发布到商店需另行操作，本次只生成本地安装包。
