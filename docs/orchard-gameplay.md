# 木牌果园玩法

用户于 2026-10-14 确认原型的探索与自由布置，并确认五条轻生活路线，要求接入正式插件。

正式首页使用现有导航、时钟与搜索。点击「我的果园」→「去果园散个步」打开探索窗口，按设备时间呈现昼夜；玩法在同一个果园里共享进度，关闭窗口即可回到导航。经典分类布局不初始化果园。

## 模块边界

- `orchard-core.js`：内容目录、V1 迁移、V2 校验、真实时间推进和所有资源操作；纯函数，可在 Node 中测试。
- `orchard-service.js`：后台唯一写入队列，每次读取最新 Chrome 本地存档再校验和提交；失败不模拟成功，队列继续可用。
- `orchard-view.js`：经确认的像素图形与页面、对话框渲染；不修改存档。
- `pixel-garden.js`：窗口、键盘、拖动、钓鱼体验与背景消息控制；提交操作而非整个页面的旧快照。
- `orchard.css`：限定于果园窗口、对话框与首页景观的样式，支持窄屏与减少动态设置。

旧数据仍位于 `chromeNav_pixelGarden_v1`，新数据位于 `chromeNav_orchard_v2`。迁移保留所有旧基础果树与最多三棵旧树苗，因此正式果树容量为七棵。未来版本存档不被静默覆盖。果园记录与飞书、网站分类、布局偏好和木牌配色互相独立。

## 成长与自由布置

树苗九小时成熟、再次结果六小时；首次浇水缩短两小时。莓果六小时成熟、薄荷三小时，苗床首次浇水缩短一小时。小雨是果园场景天气，会自动照料；不查询设备位置或天气接口。

五条经验独立积累。Lv.2 分别开放薄荷、苔藓、浅滩、草木灯与朋友的小信；Lv.3/4 为熟练度成长，不声明尚未制作的区域或系统。配方扣除真实材料，赠礼消耗料理或背包物件；重复日常操作不重复奖励。每天每种鱼只收获一次，其余相遇放归。钓鱼无操作时限，当前流程见下方 1.0.9 说明。

物件支持摆放、拖动、方向键、转向、换色、收回、复制摆放与制作。撤销来自后台产生的最近十次布置快照，恢复材料、背包与对应制作经验。发生其他资源操作时撤销历史失效，旧标签页的撤销还需匹配最新修订，避免回滚其他标签页的收获。

物件组合吸引蝴蝶、麻雀、午睡猫、河湾白鸟与夜间飞蛾；首次发现永久进入本机手记。角色关系为原创内容，小橘与小栗有不同喜好、四段故事与可翻看的小信。没有缺席惩罚、枯萎或关系衰减。

## 运行与验证

正式扩展直接加载项目目录；开发隔离预览执行 `npm run preview:orchard`，访问 http://127.0.0.1:8851/newtab.html 。预览只使用独立开发存储，不读写用户扩展数据。

`node --test tests/orchard-core.test.js` 验证迁移、规则、资源守恒、并发和失败恢复；`npm test` 运行全项目检查。`scripts/check-orchard-extension.cjs` 使用 Playwright 的 Chromium，在 `.orchard-qa/` 建立隔离扩展配置，验证实际后台与存储；可通过 `ORCHARD_PLAYWRIGHT_MODULE` 指定 Playwright 包路径，默认使用已安装的 `playwright`。

2026-10-14 本地验收：全项目 126 项测试通过；真实扩展 13 项检查通过，包括旧存档迁移、刷新恢复、跨标签同步、离线成熟苗床、指针拖动、键盘移动、撤销、错误提示、动物来访、钓鱼、390px 布局、夜间显示、原有搜索与经典布局。截图与检查报告保存在被 Git 忽略的 `.orchard-qa/`，验证使用隔离浏览器配置。`npm run package` 生成 1.0.7 安装包，仅包含正式扩展资源。

确认过的原型保存在 `codex/orchard-gameplay-prototype` 分支，仅作为设计依据。正式扩展不加载原型脚本或演示数据。

## 1.0.8 动效

钓鱼的抛竿、等待、咬钩、收线和收获具有不同动作；水面、浮标节点在操作与后台刷新时保留，让持续动效连贯。收线进度驱动浮标向岸边移动，动画仅表达界面状态，不负责奖励或资源操作。

收获、浇水、播种、拾取、制作、关系、谜题和布置的短暂反馈在操作保存成功后显示。页面与弹窗柔和进入，风铃拨动、小鱼与朋友肖像增加细微回应。尊重 `prefers-reduced-motion`；开启时停止循环和粒子动画，保留文字、进度和所有操作。隐藏页面暂停果园 CSS 动画。

`scripts/check-orchard-motion.cjs` 使用与扩展检查相同的隔离配置，检查所有玩法窗口、实际动画帧、节点连续性、保存后反馈、手机布局、减少动态模式以及设置和弹出页；结果与截图保存在 `.orchard-qa/`。

## 1.0.9 简化钓鱼

一轮只点击“抛竿”和“收线”：5–20 秒随机自动咬钩，咬钩后等待玩家，没有过期或限时失败；收线一次即由后台抽样，成功率 75%。取消张力和多次收线操作。未钓中不扣资源、种子、经验或每日鱼种收获机会，可立即再抛竿；重复钓中的鱼放归。成功保存后才呈现收获结果，保存失败保留再次收线入口。

等待计时仅属于当前钓鱼窗口，关闭、切换或卸载页面均取消；收线提交后的后台操作仍正常完成，避免未保存的乐观奖励。核心规则测试可注入随机样本，后台测试可注入随机函数；正式页面不提供结果控制或快进按钮。
