# 像素木牌 · 无分类版

独立新增原型，原来的 `../pixel-labels/` 和正式首页保留。上半部、木牌大小和间距复用原版；分类栏不显示，Shift + 滚轮也不切换分类，默认展示全部 76 个网站。实际分类仍保存在快照中，便于搜索和新增表单使用。

## 预览

在项目根目录运行：

```powershell
node docs/prototypes/orchard-directions/pixel-labels-no-categories/preview.cjs
```

打开 <http://127.0.0.1:8788/docs/prototypes/orchard-directions/pixel-labels-no-categories/index.html>。
数据复用原版从已安装扩展读取的净化快照。编辑操作仅存页面内存，刷新恢复。

## 第二轮调整

两侧增加错落的像素叶子，木牌调成更饱和的暖木色并增加淡木纹。站名使用 17px / 600 字重（窄屏 15px），木牌仍为 48px 高，原间距不变。

搜索已开启时，原搜索管理器会放行重复的 Ctrl+F，从而触发浏览器默认查找，第一次 Esc 可能被默认查找消耗。此原型增加独立键盘拦截，重复 Ctrl+F 仍阻止默认行为且保留搜索词，Esc 一次关闭自定义搜索。打开原生设置对话框时，仍由该对话框处理键盘。

回归验证：

```powershell
node --test docs/prototypes/orchard-directions/pixel-labels-no-categories/keyboard-guard.test.cjs
```

## 木牌调色

网站果园标题右侧的「调色」打开浮动面板。底色、悬停底色、描边、底部阴影、文字、木结均可取色或输入六位 HEX 色值；另有明亮度、饱和度和木纹强度滑杆。调整即时预览，并按明暗主题分别保存在当前浏览器的 localStorage 中，不改扩展导航数据。支持恢复默认与复制 CSS 参数。

默认浅木色更新为 `#f9e9cf`。每块木牌右侧上下两个 5px 像素木结使用 `--wood-knot`，不拦截点击，也不改变卡片大小和间距。

文字调节增加「文字增强」（字重 300–800）和「站名字号」（14–20px），同样即时预览、按主题保存，并包含在复制的 CSS 参数中。默认字重 600、字号 17px；窄屏字号会适当减小且不低于 14px。

果园弹层层级修复：通用顶部操作区 `z-index: 1002` 原本高于果园面板 `35`，此原型将顶部操作区降为 `20`，让果园弹层覆盖顶部按钮而不透出点击目标。

## 图标缓存

原版复现 B站、小红书远程图标缺失。52 个图标使用 Google S2 服务；即使地址能在独立请求中返回图片，浏览器加载仍可能失败。本次没有将具体原因武断归结为防盗链。

本版本将可下载的图标保存为本地文件（内容哈希命名），首页与快速搜索共同使用这份缓存。当前缓存 72 / 76 个；4 个未缓存项直接显示站名首字，打开快照页面时无需请求远程 logo。B站与小红书已缓存。

原型中新增远程图标时：先尝试已有缓存，再尝试配置地址及站点根目录 `/favicon.ico`。请求使用 `no-referrer`，每次最长 2.2 秒，总共最长 6.5 秒，全部失败就显示首字。此机制只作用于网站图标，果园素材不受影响。

更新快照后，可重新生成缓存：

```powershell
python docs/prototypes/orchard-directions/pixel-labels-no-categories/refresh-icons.py
```

缓存、映射和真实站点截图不纳入 Git。该实现仅用于新原型，正式扩展的图标存储流程尚未迁移。
