启动：在项目目录执行 `npm run prototype:home`，打开 <http://127.0.0.1:8766/>。

比较后的取舍：B 去掉卡片，避免与 A 重复；C 以分类纸面承载网站，颜色用于辨认分组；D 让果园连接启动区的草地，避免插图悬空。四版都使用项目自带的同一组 16 个演示网站。

单版地址：`/newtab.html?variant=A`（B、C、D 同理）。底部按钮及左右方向键切换，输入时方向键不切换原型。选择页支持四版并排和明暗比较。

这些是一次性设计原型；新增网站仅保存在页面内存，未连接真实飞书。A 入口现用于查看 D 正式首页，B/C/D 分别使用独立布局。开发服务器才会挂载原型与切换条，扩展打包不包含 `docs`、`scripts` 下的原型代码。

当前选择：用户已确定 D「像素果园」，正式实现见 `/newtab.html`。D 原型保留相同的玩法布局，使用共享交互模块。

## D 的果园轻互动

- 点击果树或「摘一颗」收集果子。
- 花 3 颗果子种树，最多种 3 棵。点击树苗或「浇水」三次，经历长叶、开花、结果。
- 点击成熟的小树收获自己种的果子；空树浇水后再次结果。
- 摸摸长椅旁的小猫，它会轮流回应。
- 装扮商店：2 颗换小花丛、4 颗换暖灯笼、5 颗换木栅栏。购买后可免费选择左 / 中 / 右位置，收起或摆回。
- 点击池塘或「看小鱼」触发短暂涟漪和小鱼探头；可发现蓝、橙、金三种小鱼，金色小鱼在第四次探访时出现。
- 「我的果园」展开种树、照料、装扮、互动开关和玩法说明；场景物件支持直接点击。展开「去果园散个步」可使用适合手机和键盘的替代入口。没有自动运动和声音。
- 所有成长、果篮、装扮、小鱼发现记录和临时网站都只保存在当前页面内存，刷新重置。正式持久化方案将在确认玩法后决定。

已迁移到正式首页。正式果园将进度保存在 Chrome 本地存储，原型 D 仍只使用内存状态；两者都默认收起玩法，仅显示果园入口。
