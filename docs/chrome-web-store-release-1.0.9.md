# 水果导航 1.0.9 发布说明

- 版本号：`1.0.9`
- 本地安装包：`dist/shuiguo-nav-chrome-1.0.9.zip`
- 日期：2026-10-14

钓鱼简化为每轮两次点击：抛竿后约 2–4 秒自动咬钩，玩家点击一次“收线”，后台以 75% 成功率判断是否钓中。取消手动等待、张力控制、松线和多次收线。咬钩后没有操作时限，等待期间不要求点击；没钓中不消耗资源，可立即再抛一竿。

水纹、浮标、咬钩、收线、收获与小鱼游走仍有轻柔动效；系统减少动态模式保留完整操作与提示。关闭或切换窗口会取消待咬钩计时，重新打开从抛竿开始。随机结果由后台抽样，前台不能指定成功；结果保存失败时提示重试。

成功后每天每种鱼首次收获保存鱼篓、鱼种与成长经验，重复遇见会放归，原有鱼册和存档继续保留。未钓中不占用当天收获次数。

验证覆盖概率边界、未钓中重试、重复鱼放归、并发与写入失败，以及隔离真实扩展中的自动咬钩、一次收线、失败与成功界面、关闭后计时取消、动效连续性、390px 布局和减少动态模式。本次仅生成本地安装包。
