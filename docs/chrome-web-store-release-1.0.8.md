# 水果导航 1.0.8 发布说明

- 版本号：`1.0.8`
- 本地安装包：`dist/shuiguo-nav-chrome-1.0.8.zip`
- 日期：2026-10-14

果园补充轻柔的状态动效。钓鱼包含抛竿弧线、持续水流、水纹、浮标摇晃、鱼影游动、咬钩下沉、收线靠岸与钓起小鱼。水面节点在连续操作和后台刷新时保留，避免动画重启；玩法继续由用户主动操作，没有限时失败。

收获、浇水、播种、采集、制作、朋友交谈和赠礼、发现秘密及布置成功后显示短暂反馈；弹窗和页面内容柔和进入，风铃有拨动回应，鱼册和朋友肖像有细微动作。操作反馈在后台保存成功后出现，动画不参与存档或资源判断。

系统开启“减少动态效果”时停止循环动画与粒子反馈，保留静态咬钩提示、进度、操作和保存。页面进入后台时暂停果园 CSS 动画。经典分类布局、设置页和弹出页保留原有交互。

修复从首页果园菜单打开成长手记后，下一次点击可能被菜单重绘吞掉的问题。

验证使用隔离真实扩展配置：检查各玩法窗口、浮标实际动画帧、连续收线节点、水面状态、小鱼收获、短暂操作反馈、390px 布局、减少动态模式、设置页与弹出页；同时运行全项目测试及原有果园扩展检查。本次生成本地安装包。
