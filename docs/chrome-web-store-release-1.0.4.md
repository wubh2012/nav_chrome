# 水果导航 1.0.4 商店发布说明

## 发布版本

- 版本号：`1.0.4`
- 商店上传文件：`dist/shuiguo-nav-chrome-1.0.4.zip`
- 上传方式：在 Chrome Web Store 后台上传 zip 文件，不上传解压目录

## 本次发布范围

本次发布以当前 `manifest.json` 中的 `1.0.4` 为准，发布内容基于 `1.0.3 -> 1.0.4` 的已完成功能与优化整理。

不纳入本次发布的内容：

- 当前工作区未提交的 `newtab.html`
- 当前工作区未提交的 `css/style.css`
- 上述移动端顶部布局调整不写入 1.0.4 商店更新说明

## 商店更新说明

### 推荐版本

水果导航 1.0.4 更新内容：
- 优化站点同步与拖拽排序体验，操作更顺滑
- 改进站点编辑与链接管理流程，维护导航更方便
- 调整默认主题与背景设置体验，界面更清晰
- 增强同步相关稳定性与安全性，提升整体使用可靠性

### 短版本

优化同步与排序体验，改进站点管理流程，调整主题和背景设置，并提升整体稳定性与安全性。
