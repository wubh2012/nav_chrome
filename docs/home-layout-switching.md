# 首页布局切换

设置页的「首页布局」提供两种选择：

- 木牌果园：默认保留当前首页，集中展示网站，包含果园互动和木牌调色。
- 经典分类：页面结构取自 2026 年 10 月 1 日之前的最后版本 `412ef9a`，恢复左侧分类栏、Logo 折叠侧栏、时间区域和方形网站卡片。保留现有明暗主题、字体设置、搜索和网站管理功能。

点击「保存布局」后，刷新或重新打开首页生效。偏好独立保存在 `chrome.storage.local` 的 `chromeNav_homeLayout_v1`；没有偏好或偏好无效时使用木牌果园。

两种布局共用 `newtab.html`、导航数据、编辑弹窗、排序和同步逻辑。经典布局模板在业务模块初始化前替换首页主体；果园和调色仅在木牌布局初始化。切换布局不修改网站分类、顺序、果园存档或飞书配置。

本地预览使用独立的 `chromeNav_previewHomeLayout` 键，不接触真实扩展数据。运行 `npm run prototype:home` 后，通过设置页保存布局，再返回首页检查。
