# 首屏外观快照

新标签页在样式表之前加载 `js/first-paint.js`，同步读取本扩展 localStorage 中的 `chromeNav_firstPaint_v1`。它先恢复主题模式、皮肤和主题变量，再在 body 出现时恢复已保存的木牌配色。壁纸缩略图通过单独的 `.first-paint-preview` 背景层显示，不盖住页面交互。

chrome.storage 与 IndexedDB 仍是正式设置来源。快照只是可丢弃的启动镜像；首次打开、缓存过期、数据损坏或存储不可用时，继续走原有加载流程。

## 背景交接

- 正式背景完成加载，且可见类已在动画帧中提交后，BackgroundManager 通知快照交接。
- 等待两个动画帧后淡出预览，约 220ms 后清理临时属性；首次交接期间正式图片不再额外执行一次透明度过渡。
- 默认背景和图片失败恢复默认也发送就绪通知。慢网络、初始化异常或动画帧暂停时，3 秒后强制撤下预览，避免长期显示旧图。
- 遵循减少动态效果偏好；页面离开前清除预览和定时器，避免从浏览器往返缓存恢复时停在过渡状态。

## 缩略图缓存

- 原图显示后再异步生成，按原始比例缩至最大 640 × 480；单张编码数据不超过 160 KiB，超限会再尝试 320 × 240 和较低质量。
- 只保存 WebP / JPEG / PNG 的 base64 图片，不持久化临时 Blob URL。快照和每张缩略图均有 30 天有效期，总序列化读取上限为 400 KiB。
- 浅色、深色的图片与木牌外观分别保存。快照记录尺寸、位置、模糊和遮罩设置，预览与正式背景一致。
- 上传图片直接使用已加载的本地图片生成。远程图像从已配置的壁纸地址读取二进制后生成，优先 HTTP 缓存，不带 Cookie 和 Referer；补充读取限制为 8 MiB、2.5 秒，失败仅省略缩略图。
- 相同背景签名不重复编码；未改变的主题和配色避免反复同步写入整份快照。
- 设置中的背景配置变化会使对应模式失效；迟到的旧请求、清缓存前的请求不得把图片写回。离开页面或清理缓存时取消仍在获取的缩略图请求。
- 设置页清缓存和重置会一并删除首屏镜像，正式偏好不随清缓存删除。

## 验证

行为测试覆盖同步恢复、数据校验、过期与容量限制、双帧交接、减少动态效果、超时兜底、按模式失效、迟到请求、配额失败、默认/失败背景就绪，以及设置页清理。

全量 163 项测试通过；UTF-8、JavaScript 语法、页面资源引用与 git diff 空白检查通过。

独立 Chrome 扩展资料目录中的检查覆盖：深色网络壁纸、浅色上传壁纸、木牌自定义颜色、经典布局、慢请求期间缩略图先显示、正式背景就绪后退出预览，以及图片失败只清除对应模式快照。将网络壁纸响应延迟 2.2 秒时，实际观察到正式图片尚未可见、缓存预览透明度为 1，主题和木牌颜色均已正确恢复；浏览器没有页面运行错误。测试未读写用户实际浏览器数据。
