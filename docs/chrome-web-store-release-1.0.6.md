# 水果导航 1.0.6 商店发布说明

## 发布版本

- 版本号：`1.0.6`
- 商店上传文件：`dist/shuiguo-nav-chrome-1.0.6.zip`
- 上传方式：在 Chrome Web Store 后台上传 zip 文件，不上传解压目录

## 本次发布范围

本次发布重点升级背景设置体验：浅色和深色模式现在可以分别保存背景图片与显示参数，并在切换明暗模式时自动使用对应背景。

旧版用户已有的单背景配置会自动迁移到升级时正在使用的明暗模式，无需重新上传图片或填写 URL。石墨、霓虹和奶油皮肤继续共用浅色、深色两套背景，不会额外占用多份存储。

## Chrome Web Store 更新说明

### 推荐版本

水果导航 1.0.6 更新内容：

- 新增浅色、深色模式独立背景，可分别设置上传图片或图片 URL
- 背景适配、遮罩强度和模糊效果支持按明暗模式独立保存
- 切换明暗模式时自动预加载并平滑切换对应背景
- 自动迁移旧版自定义背景，已有图片和设置无需重新配置
- 优化背景设置界面，新增模式标签、背景预览和键盘操作支持
- 增强背景加载容错，图片失败时仅恢复当前模式的默认背景

### 短版本

新增浅色、深色模式独立背景及预览，支持平滑切换和旧配置自动迁移，并增强背景加载稳定性。
