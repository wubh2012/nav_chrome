# 水果导航 1.0.6 商店发布说明

## 发布版本

- 版本号：`1.0.6`
- 商店上传文件：`dist/shuiguo-nav-chrome-1.0.6.zip`
- 上传方式：在 Chrome Web Store 后台上传 zip 文件，不上传解压目录

## 本次发布范围

本次工作区构建增加已确定的 D 像素果园首页，玩法默认收起为「我的果园」，果园进度保存在本地；同时包含背景设置升级：浅色和深色模式现在可以分别保存背景图片与显示参数，并在切换明暗模式时自动使用对应背景。

旧版用户已有的单背景配置会自动迁移到升级时正在使用的明暗模式，无需重新上传图片或填写 URL。石墨和果园晨光皮肤继续共用浅色、深色两套背景，不会额外占用多份存储。

## Chrome Web Store 更新说明

### 推荐版本

水果导航 1.0.6 工作区构建更新内容：

- 新增霞鹜文楷 TC、站酷快乐体、缝合像素及系统字体选项，全页统一字体并支持 14–20 px 正文大小
- 字体随扩展离线提供，新增中文实时预览及保存后跨页面即时更新
- 设置页统一采用果园配色，保留飞书、背景与数据管理功能
- 首页采用像素果园场景、中心时钟、横向分类和网站图标启动区
- 摘果、种树、逗猫、池塘小鱼及装扮按需展开，首页不再堆放玩法按钮
- 果篮、成长、装扮与位置、小鱼记录和互动开关在本地保存
- 手机上的网站编辑和删除收进「整理网站」入口

- 新增浅色、深色模式独立背景，可分别设置上传图片或图片 URL
- 背景适配、遮罩强度和模糊效果支持按明暗模式独立保存
- 切换明暗模式时自动预加载并平滑切换对应背景
- 自动迁移旧版自定义背景，已有图片和设置无需重新配置
- 优化背景设置界面，新增模式标签、背景预览和键盘操作支持
- 增强背景加载容错，图片失败时仅恢复当前模式的默认背景

### 短版本

新增浅色、深色模式独立背景及预览，支持平滑切换和旧配置自动迁移，并增强背景加载稳定性。
